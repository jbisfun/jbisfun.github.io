issues

Reports filed with radar. Each one records a repo, file, line, the line’s text, a note and when it was filed.

  • radar.db/: the PoloDB database, which is the source of truth.
  • docs/: one page per open report plus index.md, generated by radar export in the pull precommit hook. It’s gitignored; the wiki publishes it.
