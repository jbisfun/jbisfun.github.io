phone-ios

Fossify Phone re-created for iOS in SwiftUI, on top of the system contact store (Contacts.framework); calls are placed through tel: URLs.

idl build -c release     # -> build/release/FossifyPhone.ipa (ad-hoc signed; re-sign to install)
idl install "<device>" FossifyPhone

Ported: contacts/favorites/call history tabs with search, letter fast scroller, multi-select actions, sorting and source filter; favorites with custom order and grid view; dialpad with T9 contact search, speed dial, DTMF beeps and vibrations; call confirmation and number chooser; call history grouped by day and subsequent calls, call details, block/delete/copy/SMS actions, JSON export/import; blocked numbers; colors, font size, date/time format and every applicable setting.

Differences forced by iOS: no call log access, so the call history holds the calls started from this app (durations via CallKit’s observer) plus imported ones; no dialer role, so there is no in-call screen, incoming call handling, call screening, SIM selection, number location or secret codes (and their settings); blocked numbers only hide calls in the app and stop calls from it; favorites are stored by the app; contacts are viewed and created in the system contact screens; launcher shortcuts don’t exist.

GPL-3.0, like the original.
