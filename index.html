pull

A multi-repo git wrapper. pullfile.plist lists the repos, their upstreams and pinned commits. Each repo is cloned to {pullfile-root}/{repo-name}. A single pull commit writes one commit, with the same message, identity and signature, to every repo that has changes, then records the new pins.

ycode-manager

Mod manager for ycode’s Lua hooks. A button in the status bar (blocks icon), or “manager: open” in the command palette, opens a window that lists every mod in ~/.config/zed/hooks, with its description (the first comment line of its hook file), where it links to, and whether it is enabled.
