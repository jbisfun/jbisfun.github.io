ios-webusb

A WebUSB driver for iPhones and iPads. The web page claims the device through navigator.usb and runs the driver itself in wasm: (vendored, ported to WebUSB) for the usbmux protocol, and for lockdown, pairing and services. No daemon, no extension, nothing native. Works in Chromium-based browsers.

pull

A multi-repo git wrapper. pullfile.plist lists the repos, their upstreams and pinned commits. Each repo is cloned to {pullfile-root}/{repo-name}. A single pull commit writes one commit, with the same message, identity and signature, to every repo that has changes, then records the new pins.

pull @ 75ae20e · Rust API

radar

Reports for agents. Each report points at a line of code in the pull workspace and records the repo, the file, the line number, the line’s text, an optional note, and when it was filed. The CLI is stateless: every run opens the PoloDB database at <workspace>/issues/radar.db, does its work and exits.

radar @ 95e97c9 · Rust API
