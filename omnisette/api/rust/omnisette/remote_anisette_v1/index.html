Module remote_anisette_v1 

Source
Expand description

Classic “v1” anisette provider: a plain HTTPS GET that returns the anisette headers as a flat JSON object. This is the format used by the original anisette servers and by Sideloadly’s remote endpoint (.../anisette/<id>?u=<device-hash>).

No token or account is sent — this is the free, rate-limited path. A random per-install device hash is persisted so the server returns a stable identity across refreshes.
