Module adi_libraries 

Source
Expand description

Fetching Apple’s ADI libraries (used by local and fake anisette).

The libraries ship inside the Apple Music APK. Instead of downloading the whole APK (~140 MB), we read its zip central directory with HTTP range requests and only fetch the two libraries we need.
