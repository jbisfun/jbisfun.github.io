idlci: a local CI service for idl projects in a pull workspace.

Modules§

client 🔒
HTTP client for a running idlci serve (MCP server and CLI), starting one if needed.
db 🔒
Job model and the SQLite store ($ROOT/.pull/idlci/idlci.db).
mcp 🔒
idlci mcp: stdio MCP server for agents, a thin layer over the idlci serve HTTP API (started on demand).
projects 🔒
idl projects in the workspace: discovery, idl list targets, git state.
runner 🔒
Workers: run queued jobs as idl process groups, log to logs/<id>.log.
watch 🔒
serve --watch: poll the repos of every project (and of its targets’ dirs) and queue build then test when a HEAD moves.
web 🔒
idlci serve: axum web UI + JSON API over the queue, with the workers in-process.
