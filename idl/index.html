iOS development on Linux

idl is a small Zig tool that builds Objective-C, Swift, C and C++ iOS apps on Linux. One file, idlproj.yml, configures the toolchain and every app. From that file idl:

  • generates code: deterministic .xcodeproj projects with a shared scheme, xtool.yml + Package.swift for xtool, and compile_commands.json for clangd / sourcekit-lsp
  • runs builds: it calls clang, swiftc, xtool’s ld64.lld and ldid, processes Info.plist, compiles storyboards, XIBs and asset catalogs, copies resources, ad-hoc signs, writes the IPA, and checks the result

The build steps come from the Linux build used by LiveContainer.

Quick start

xtool setup                   # Darwin SDK -> ~/.swiftpm/swift-sdks/darwin.artifactbundle
zig build                     # builds ./zig-out/bin/idl (Zig 0.14.1)
./zig-out/bin/idl check       # verify the toolchain
zig build actool              # optional: .xcassets compiler (needs swift)
./zig-out/bin/idl build --strict -c release  # preflight, then build every example

Install on a phone through Jimpactor, a sideloading tray app that signs the IPA with your Apple account (other options in workflows):

idl devices list
idl install "My iPhone" MyApp

Start a new app:

idl init MyApp --lang swift --bundle-id com.example.myapp
cd MyApp && idl build

Build automation

idl check --strict -c release
idl build --strict -c debug MyApp
idl build --strict -c release MyApp

YAML configurations: overrides flags, bundle identity, metadata and entitlements. Debug/release artifacts are isolated. Direct builds cache resource compilation, bundling, signing and packaging; concurrent build/gen/clean operations are locked. See workflows.

Code quality

idl fmt [--check]      # clang-format (C/ObjC/C++/ObjC++) + swift-format, configs generated from YAML
idl lint [--analyze]   # clang -Wall, swiftc -typecheck, clang-tidy, analyzer, all with the real build flags
idl test               # bundle checks (arm64/iOS/signed, @rpath resolution, plists) + `tests:` commands

idl only orchestrates installed tools and merges their diagnostics into one report. See configuration.

Layout

idlproj.yml        configuration for the examples in this repository
build.zig(.zon)    Zig build; pulls zig-clap, zig-yaml, zig-xml and libplist
src/               the idl tool (see docs/architecture.md)
tools/idl-actool/  Swift wrapper around AssetKit for .xcassets
examples/          ObjC, Swift, storyboard/XIB/asset-catalog and xtool/SwiftPM
                   apps, plus xcconfig patterns
docs/              documentation

Tests

zig build test       # unit tests (config, plist, pbxproj, zip, Mach-O, nib, ibtool, ...)
zig build check      # idl check
zig build examples   # idl build --gen for every example (real arm64 builds)

Ad-hoc ldid signatures are not provisioning. Re-sign an IPA with your usual signing or sideloading tool before you install it.
