pub fn begin_session(&mut self) -> Result<Reply, Error>

Start a session the way a fresh process would: reset the VM to its post-load snapshot (the store, host UUID and clock are kept) and call Initialize. One session is, for example, one Anisette header set (is_machine_provisioned, request_otp, get_routing), or one provisioning (provisioning_start then provisioning_end, which must share a session). This replaces the heap management a long-lived library would need: nothing accumulates.
