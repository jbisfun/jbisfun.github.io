Module capi 

Source
Expand description

C ABI over CoreAdi, for JNI (see jni.rs) or any C host. Every function returns 0 on success and a negative value on failure, with the message available from adi_last_error (per thread). Output buffers are allocated here and must be released with adi_buf_free.

A handle may be used from one thread at a time (calls are serialised by a mutex); prefer a single-threaded executor, because each call is one 20 ms emulated session.
