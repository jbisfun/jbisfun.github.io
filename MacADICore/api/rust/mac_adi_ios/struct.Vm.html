pub fn reset_session(&mut self) -> Result<(), Error>

Return the VM to the state it had right after loading, as if a fresh process had started. The store (files), host UUID and clock are kept; library memory (data segment, heap, stack, scratch), descriptors and allocator counters are not. Translated code stays cached, which is what makes this cheap, and nothing leaks because the heap restarts from empty. Call it between sessions, never inside one (a provisioning session id lives in library memory).

pub fn set_frozen_time(&mut self, secs: Option<u64>)

Pin gettimeofday to secs (tests, byte-for-byte comparison); None restores the real clock.

Never do this in the app. A frozen clock makes CoreADI’s OTP a constant, and Apple then accepts the machine for only about 60 s (EVIDENCE.md sections 8 and 9). Production must leave it None.
