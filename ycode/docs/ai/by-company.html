AI by Company

Use this page when you know the company, subscription, provider, agent, or CLI you want to use in Zed.

For detailed setup, follow the links in the Setup column. This page answers routing questions; it does not replace the setup pages.

Zed

Path Support level What you get Account / billing Setup
Zed-hosted models Built into Zed Hosted models for Zed AI features Billed through Zed Zed-Hosted Models
Zeta edit prediction Built into Zed Edit predictions while you type Included by plan limits Edit Prediction

OpenAI / ChatGPT / Codex

Path Support level What you get Account / billing Setup
ChatGPT Subscription Configured in Zed Subscription-backed OpenAI models for Zed AI features ChatGPT Plus or Pro Use an Existing Subscription
OpenAI API Configured in Zed OpenAI models through API access OpenAI API billing Use API Access
Codex via ACP Hosted in Zed Codex in an External Agent thread Owned by Codex/OpenAI External Agents
Codex CLI Run in terminal Native Codex CLI experience in a Terminal Thread Owned by Codex/OpenAI Terminal Threads

Anthropic / Claude / Claude Code

Path Support level What you get Account / billing Setup
Anthropic API Configured in Zed Claude models through API access Anthropic API billing Use API Access
Claude Agent via ACP Hosted in Zed Claude in an External Agent thread Owned by Claude/Anthropic External Agents
Claude Code CLI Run in terminal Native Claude Code experience in a Terminal Thread Claude subscription or Claude Code auth Terminal Threads

Claude Pro and Max subscriptions are separate from Anthropic API credits. If you want Claude subscription-limit behavior, use Claude Agent or Claude Code where supported. See Use an Existing Subscription.

Google / Gemini / Gemini CLI

Path Support level What you get Account / billing Setup
Google AI API Configured in Zed Gemini models through API access Google AI API billing Use API Access
Gemini CLI Hosted in Zed or run in terminal Gemini CLI as an External Agent or native CLI/TUI Owned by Gemini CLI External Agents, Terminal Threads

GitHub / Copilot

Path Support level What you get Account / billing Setup
GitHub Copilot Chat Configured in Zed Copilot Chat models for Zed AI features GitHub Copilot/Copilot Chat Use an Existing Subscription
Copilot edit prediction Built into Zed Edit prediction provider option GitHub Copilot Edit Prediction
Copilot External Agent Hosted in Zed Copilot in an External Agent thread, where available Owned by Copilot External Agents
Copilot CLI Run in terminal Native CLI experience, where available Owned by Copilot Terminal Threads

OpenCode / Zen / Go

Path Support level What you get Account / billing Setup
OpenCode provider Configured in Zed OpenCode models for Zed AI features OpenCode API key; Zen or Go affects available models Use API Access
OpenCode External Agent Hosted in Zed OpenCode in an External Agent thread, where available Owned by OpenCode External Agents
opencode CLI Run in terminal Native OpenCode CLI experience Owned by OpenCode Terminal Threads

Cursor

Path Support level What you get Account / billing Setup
Cursor External Agent Hosted in Zed Cursor in an External Agent thread, where available Cursor account/subscription External Agents
Cursor CLI/TUI Run in terminal Native Cursor command-line experience, where available Cursor account/subscription Terminal Threads

Cursor subscriptions do not configure Zed’s LLM provider settings. If you want to use a work Cursor subscription in Zed, use the Cursor External Agent or a Terminal Threads workflow where available.

Pi Coding Agent

Path Support level What you get Account / billing Setup
Pi Coding Agent Hosted in Zed Pi in an External Agent thread, where available Owned by Pi External Agents
Pi CLI/TUI Run in terminal Native Pi command-line experience, where available Owned by Pi Terminal Threads

Pi is an agent harness, not a Zed LLM subscription. Pi may support provider auth such as ChatGPT, Claude, or Copilot through its own setup flow.

Poolside

Path Support level What you get Account / billing Setup
Poolside External Agent Hosted in Zed Poolside in an External Agent thread Poolside or configured provider External Agents
pool CLI Run in terminal Native Poolside Agent CLI experience Poolside or configured provider Terminal Threads

Install Poolside from the ACP Registry, configure Zed with the Poolside Agent CLI, or add Poolside as a Custom Agent. See External Agents for setup steps and platform-specific details.

DeepSeek

Path Support level What you get Account / billing Setup
DeepSeek API Configured in Zed DeepSeek models for Zed AI features DeepSeek API credits, top-ups, or usage billing Use API Access

Paid DeepSeek usage is API access in Zed, not subscription sign-in.

Gateways and Cloud Platforms

Provider Support level What you get Account / billing Setup

Vercel AI Gateway Configured in Zed Gateway access through Vercel Vercel billing Use a Gateway
Amazon Bedrock Configured in Zed AWS-hosted model access AWS billing Use a Gateway
