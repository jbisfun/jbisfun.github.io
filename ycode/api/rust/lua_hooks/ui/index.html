gpui for Lua: gpui.open_window{...} / gpui.register_panel{...} render a tree of Lua tables on every frame, built from Zed’s own ui components so Lua panels look like the native ones without any styling in the plugin.

gpui.register_panel{ id = "demo", title = "Demo", icon = "box", position = "right",
    render = function(w)
        return { "panel",
            header = { title = "Demo", context = "3 items",
                       actions = { { "icon_button", icon = "rotate_cw", tooltip = "Refresh",
                                     on_click = function(w) end } } },
            footer = w.state.message,
            { "section", "Items", action = { "icon_button", icon = "plus", tooltip = "Add" },
                { "list_item", "first", detail = "a detail", selected = true,
                  start = { "icon", name = "file" }, on_click = function(w) end },
            },
            { "toolbar", { "button", "Build", on_click = build }, { "button", "Test" } },
        }
    end }

An element is { tag, children..., props }; bare strings and numbers are text. Props are typed: an unknown or mistyped prop is an error drawn in place of the element. Sizes and spacing are names, never pixels (pixel numbers still work but log a deprecation once).

Structure (these carry Zed’s spacing, so plugins don’t pick any):

  • panel{ header, footer, scroll = true, children }: header is a title string or { title, context, actions = {...} } (tab-bar height, bottom border); the body fills the rest and scrolls with a scrollbar unless scroll = false; footer is a string (small, muted, truncated; color applies to it) or an element.
  • section{ "Title", action = el, empty = "nothing here", children }: a list sub-header (small, muted) followed by its rows.
  • toolbar{ children }: a wrapping row of buttons with toolbar padding.
  • split{ a, b, ratio, vertical }: two panes with a divider. Horizontal splits give the first pane a sidebar width unless ratio (0..1) is set; vertical ones split evenly by default.
  • empty{ "message", action = el }: centered muted text for empty/loading/error states.
  • panel_header{ title, context, actions | children }, divider{ vertical }.
  • col (default tag), row (children vertically centered): plain flex containers with gap p px py (none xs sm md lg xl), w h ("full", "sidebar"), grow, align (start center end), justify (center end between), bg border (theme color names), rounded, scroll, id, on_click.

Content:

  • text{ "...", size, color, mono, bold, truncate } (ui::Label; size is default small xsmall large; color is a theme color such as muted accent error warning success; fg is an alias).
  • list_item{ "label" | children, detail, selected, indent, start, end_, end_hover, on_click } (ui::ListItem: hover/selected background, full-row hit target; detail is small muted text after the label; end_hover replaces end_ on hover).
  • list_header{ "label", sub, start, end_, end_hover, on_click }.
  • button{ "label", style = subtle|filled|transparent, icon, tooltip, disabled, on_click }, icon_button{ icon, tooltip, disabled, on_click }.
  • icon{ name, size, color }, checkbox{ checked = true|false|"mixed", label, size, disabled, on_click }, toggle_group{ options, selected, on_select = fn(w, opt) }, disclosure{ open, on_click }.

gpui.open_window also takes kind = "floating" (stays above the focused window, not tiled) or "dialog" (modal), besides title width height state focus poll_ms on_key render.

  • input{ id, placeholder, multiline }: read/write with w.text(id)/w.set_text.

Inside callbacks, w has state, text(id), set_text(id, s), focus(id), scroll_bottom(id), refresh() and close().
