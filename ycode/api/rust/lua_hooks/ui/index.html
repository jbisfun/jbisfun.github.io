gpui for Lua: gpui.open_window{...} opens a real gpui window whose content is rendered from Lua tables on every frame.

gpui.open_window{
    title = "hello", width = 600, height = 400,
    state = { n = 0 },             -- persistent table, available as w.state
    focus = "name",                -- input to focus on open
    poll_ms = 500,                 -- re-render periodically (optional)
    on_key = function(w, ev) ... return true end,   -- ev.key/ctrl/alt/shift/cmd/char; true = consumed
    render = function(w)
        return { "col", p = 8, gap = 4,
            { "text", "clicked " .. w.state.n .. " times", fg = "muted" },
            { "input", id = "name", placeholder = "type here" },
            { "button", "Click", on_click = function(w) w.state.n = w.state.n + 1 end },
        }
    end,
}

Elements are { tag, children..., props } with tag col (default), row, text, button, icon_button, icon, checkbox, toggle_group, divider, panel_header, list_item, list_header, disclosure, input. Strings and numbers are text. Props:

  • button (native ui::Button, LabelSize::Small): label is the first string child (or label), style = "subtle" (default) | "filled" | "transparent", icon, tooltip, disabled, on_click = fn(w)
  • icon_button (native ui::IconButton, IconSize::Small): icon (required, snake_case/kebab-case IconName, e.g. "settings"), tooltip, disabled, on_click = fn(w)
  • icon (native ui::Icon): name (required, same IconName parsing as icon_button), size ("indicator"/"xsmall"/"small"/"default"/"large"), color (named theme color or #rrggbb[aa], same as text’s color)
  • checkbox (native ui::Checkbox): checked = true | false | "mixed" ("mixed" is ToggleState::Indeterminate), label, disabled, on_click = fn(w)
  • toggle_group (native ui::ToggleButtonGroup, 1-6 options): options (list of strings), selected (one of options), on_select = fn(w, option)
  • divider (native ui::Divider): vertical (default horizontal)
  • panel_header (height Tab::container_height, bottom border): title (Default-size Label), context (optional Small muted Label), children render right-aligned as actions
  • layout: p px py gap w h (pixels, or "full" for w/h), grow, align (start/center/end; row defaults to center, use align = "start" to opt out), justify (center/end/between)
  • look: bg fg border (theme names: background surface panel editor element text muted accent border error warning success, or #rrggbb[aa]), rounded mono bold, size ("default"/"small"/"xsmall"/"large", follows ui_font_size; a raw number is accepted for back-compat but is a fixed px size and logs a deprecation warning)
  • behaviour: id, scroll = true (vertical scroll; needs/uses id), on_click = fn(w)
  • text renders a native ui::Label (never the window’s root text size), so bare strings elsewhere in a tree also render at Label’s default (14px) size. text-only props: size ("default"/"small"/"xsmall"/"large"), color/fg (named or #rrggbb[aa]), mono (buffer font instead of the UI font), truncate (ellipsis).
  • inputs (id required): multiline, placeholder; read and write them with w.text(id) and w.set_text(id, s)

Inside callbacks, w also has focus(id), scroll_bottom(id), refresh(), close() and state.
