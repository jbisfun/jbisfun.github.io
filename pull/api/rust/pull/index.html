Crate pull 

Source
Expand description

pull: the CLI. The core (repos, sync, status, commit, push) lives in pull-core and pull-git; every other feature is an optional crate behind a cargo feature, wired in through workspace (hooks, lint, env, ignore) or its own subcommands.

Modules§

cli 🔒
Command-line interface. Subcommands of compiled-out features don’t exist.
launchd 🔒
pull launchd / pull launchctl / pull session (the launchd feature).
workspace 🔒
Glue between the core and the optional features: each helper does the feature’s work when it is compiled in and a neutral fallback otherwise, so commands never need to know which features exist.
