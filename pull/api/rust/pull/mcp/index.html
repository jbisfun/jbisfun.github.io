pull mcp: an MCP server (stdio) over the workspace, for agents.

Multi-repo context (workspace overview, status, diffs, logs, search, files), programs (one-shot commands with the workspace env) and stateful terminals (the launchd sessions: they persist between calls and across agents, and a human can attach to the same terminal with pull session attach).
