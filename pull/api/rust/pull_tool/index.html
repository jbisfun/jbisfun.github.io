Workspace packages: the pullfile tool section is a Brewfile-shaped package list (tap, brew) that jbisfun/tool pours from Linuxbrew bottles into its shared store and links into the workspace profile .pull/tool/. The env adds the profile’s bin/sbin to PATH.
