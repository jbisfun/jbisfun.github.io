The pull workspace model: pullfile.plist (shared, committed), local.toml (per-machine, ignored), commit identity, and routing user paths to repos.

Only identity and repos belong to the core. Every other top-level key is a section owned by an optional feature crate (env, lint, hooks, ignore, jobs, …): it is kept as raw plist and parsed by its owner with Pullfile::section, so a pull built without that feature still round-trips it.
