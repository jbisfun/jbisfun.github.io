Crate pull_launchd 

Source
Expand description

A port of launchd’s job model to pull (Linux and macOS, per workspace).

Jobs use launchd’s plist keys (see Apple’s liblaunch/launch.h) and live in the pullfile’s jobs array or in standalone .plist files loaded with pull launchctl load FILE. Unlike launchd, every job runs in a pseudo-terminal managed by the workspace daemon (pull launchd), so any job is also a tmux-style session: a human can attach to it, and an agent can send input and read its screen.

Supported job keys: Label, Program, ProgramArguments, EnvironmentVariables, WorkingDirectory, RunAtLoad, KeepAlive (bool or {SuccessfulExit}), StartInterval, ThrottleInterval, StandardOutPath, Disabled, LaunchOnlyOnce. A PTY merges stdout and stderr, so StandardErrorPath is accepted but the combined output goes to StandardOutPath.
