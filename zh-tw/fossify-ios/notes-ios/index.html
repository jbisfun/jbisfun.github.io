notes-ios

Fossify Notes 以 SwiftUI 在 iOS 上重新打造。

idl build -c release     # -> build/release/FossifyNotes.ipa (ad-hoc signed; re-sign to install)
idl install "<device>" FossifyNotes

已移植：文字筆記與待辦清單，置於可滑動的分頁中並附筆記標題列；復原／重做、搜尋（系統尋找列）、字數統計、可點選的連結、等寬字型、對齊方式、字型大小與自動換行；待辦清單支援勾選／取消勾選、已勾選項目收合於底部、排序（每份清單亦可個別排序）、拖曳重新排列、移至頂端／底部、重新命名、刪除與多行新增；含預覽的開啟筆記格狀檢視、新增／重新命名／刪除筆記、以圖形密碼、PIN 或 Face ID／Touch ID 鎖定筆記；開啟檔案與資料夾（複製或與檔案保持同步）、開啟來自其他應用程式的文字檔、匯出為檔案、分享、列印；以 JSON（Fossify 的格式）匯出／匯入所有筆記、自動備份（檔案 › 在我的 iPhone 上 › Notes › Backups 或所選資料夾）；筆記主畫面小工具（文字或待辦清單、標題切換、背景色彩與透明度、文字色彩、附鎖定檢查的筆記選擇器）；自動儲存或手動儲存並附未儲存變更提示、應用程式與刪除密碼保護、色彩，以及所有適用的設定。

因 iOS 而不得不有的差異：小工具僅能在 launcher-ios 內使用（iOS 主畫面小工具需要 WidgetKit 擴充功能加上 App Group），因此應用程式內沒有「自訂小工具色彩」設定；沒有啟動器或釘選筆記捷徑；從其他應用程式分享的文字無法加入筆記（需要分享擴充功能）；自動備份改為在上午 6 點後開啟應用程式時執行，而非由鬧鐘觸發；「無痕模式」會關閉自動修正與預測輸入（iOS 鍵盤沒有無痕旗標）；沒有應用程式內語言切換。

GPL-3.0，與原版相同。
