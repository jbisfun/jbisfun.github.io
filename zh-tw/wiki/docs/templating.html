範本

儲存庫的 docs/（或 wiki/pages/）中的任何 .jinja 檔案都是一個頁面，使用 minijinja（Jinja2 語法）渲染。本頁是 wiki/docs/templating.jinja。版面配置與局部範本位於 wiki/templates。

標籤

{% for x in xs %}{% endfor %}陳述式（迴圈、if、set）
{{ value }}輸出，並進行 HTML 跳脫
{{ html | safe }}輸出原始 HTML
{% include "partials/footer.html" %}引入 wiki/templates 中的範本

變數

  • site：title、home（此語言的首頁）、lang、repos、pages（{title, out}）
  • repo：目前的儲存庫（name、title（不含 pull 群組的名稱）、category、description、index、readme_page、doc_pages、apis（{tool, title, label, out}）、web、head、...）
  • page：title、out、rel、lang、translation（"machine"、"missing" 或無）、original（英文頁面）、alternates（{lang, name, out, current}），front matter 為 page.data
  • t(key, **args)：頁面語言在 locales/<lang>/main.ftl 中的訊息
  • url(path)：從本頁連結過去的網站相對路徑
  • md(source)：渲染 markdown

Front matter 中的 layout: false 會略過 templates/layout.html；layout: other.html 則改用另一個版面配置。Markdown 頁面可以用 jinja: true 選擇啟用 Jinja。範本頁面在每次建置時都會渲染，因為它們可以顯示網站的任何資訊。
