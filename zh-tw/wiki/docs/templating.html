範本處理

儲存庫中 docs/（或 wiki/pages/）目錄下的任何 .jinja 檔案都是一個頁面，使用 minijinja（Jinja2 語法）進行渲染。此頁面為 wiki/docs/templating.jinja。版面配置與局部範本位於 wiki/templates。

標籤

{% for x in xs %}{% endfor %}陳述式（迴圈、條件判斷、set）
{{ value }}輸出，HTML 跳脫字元處理
{{ html | safe }}輸出原始 HTML
{% include "partials/footer.html" %}包含來自 wiki/templates 的範本

變數

  • site：title、home（此語言的家頁面）、lang、repos、pages（{title, out}）
  • repo：目前的儲存庫（name、title（wiki.toml 中的 title，否則為不含拉取群組的名稱）、category、description、index、readme_page、doc_pages、apis（{tool, title, label, out}）、web、head、...）
  • page：title、out、rel、lang、translation（"machine"、"missing" 或無）、original（英文頁面）、alternates（{lang, name, out, current}）、前置資訊作為 page.data
  • t(key, **args)：來自頁面語言之 locales/<lang>/main.ftl 中的訊息
  • url(path)：從此頁面到連結的網站相對路徑
  • md(source)：渲染 Markdown

前置資訊 layout: false 會跳過 templates/layout.html；layout: other.html 則選擇另一個。Markdown 頁面可以透過 jinja: true 啟用 Jinja。範本頁面會在每次建置時渲染，因為它們可以顯示關於網站的任何資訊。
