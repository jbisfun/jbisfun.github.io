Usage

Any usage of a Zed-hosted model will be billed at the Zed Price (rightmost column above). See Plans & Pricing for details on Zed’s plans and limits for use of hosted models.

For Claude Fable 5.2, the cache-write rate above is for the 5-minute cache. The 1-hour cache costs $16.00 per 1M tokens from Anthropic, or $17.60 through Zed. Fast mode doubles all Fable 5.2 token rates, including cache writes and reads.

Fast mode for GPT-6.2 Astra and Sol is available on Zed Pro and Zed Business. It doubles all token rates, including cache writes and reads.

Zed bills implicit cache hits for Gemini 4 at the cached-input rates above. Gemini 3 models do not use Google context caching and are billed only as input and output tokens, which preserves zero-data-retention behavior for those requests. For background, see Google’s Vertex AI documentation on context caching and zero data retention.

LLMs can enter unproductive loops that require user intervention. Monitor longer-running tasks and interrupt if needed.
