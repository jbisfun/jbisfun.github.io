tool

Declarative Homebrew packages per project, a little like a nix profile.

  • Package list: Brewfile-shaped (tap, brew). Standalone tool reads a Brewfile; in a pull workspace the list lives in the pullfile tool section (pull tool).
  • Store: one shared Homebrew-layout prefix (Cellar/<name>/<version>, opt/<name>) in $TOOL_HOME (default ~/.local/share/tool). Kegs are Linuxbrew bottles from formulae.brew.sh / ghcr.io, poured and relocated into the store (ELF interpreter -> the system loader, RUNPATHs -> opt/<dep>/lib, via patchelf). Bottles are cached in $TOOL_CACHE (default ~/.cache/tool).
  • Profiles: a directory of symlinks to the requested formulae (bin/, lib/, share/ …), rebuilt and swapped in atomically on every sync. Every profile is a GC root; tool gc deletes kegs no live profile uses.

Requires patchelf. Only homebrew/core formulae; casks/mas/vscode entries are ignored. Building bottles from source is planned; for now everything is poured from Linuxbrew bottles.

Standalone

printf 'brew "jq"\nbrew "ripgrep"\n' > Brewfile
tool sync            # pour into the store, link ./.tool
eval "$(tool env)"   # .tool/bin on PATH
tool list
tool gc

In a pull workspace

pull tool add jq ripgrep      # pullfile `tool` = {brew = [jq, ripgrep]}, then sync
pull tool import Brewfile     # merge an existing Brewfile into the pullfile
pull tool sync                # links $PULL_ROOT/.pull/tool
pull env                      # PATH includes $PULL_ROOT/.pull/tool/bin

Pullfile section:

<key>tool</key>
<dict>
  <key>brew</key>
  <array>
    <string>jq</string>
    <dict><key>name</key><string>openssl@3</string><key>link</key><false/></dict>
  </array>
</dict>

Built on the stout crates (stout-bundle, stout-fetch, stout-install, stout-resolve).
