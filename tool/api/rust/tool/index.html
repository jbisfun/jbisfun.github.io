Expand description

tool: declarative, per-project Homebrew packages, a little like a nix profile.

  • Package list: Packages, Brewfile-shaped (tap / brew). Read from a Brewfile (Packages::from_brewfile) or stored anywhere serde reaches (pull keeps it in the pullfile tool section).
  • Store: one shared Homebrew-layout prefix (Cellar/<name>/<version>, opt/<name>) under $TOOL_HOME (default ~/.local/share/tool). Kegs are Linuxbrew bottles poured and relocated into it; bottles are cached under $TOOL_CACHE (default ~/.cache/tool).
  • Profiles: a directory of symlinks into the store for the requested formulae (bin/, lib/, share/, …), swapped in atomically by sync. Each profile is a GC root: gc deletes kegs no live profile needs.

api
Formula metadata from the Homebrew JSON API (https://formulae.brew.sh/docs/api/), seen from Linux: per-platform variations replace the macOS dependency lists and uses_from_macos entries become real dependencies, as Homebrew does on Linux.
