Module render 

Source
Expand description

Pages: every repo’s README (its entry page) and docs/ folder, plus the wiki’s own pages/*.jinja, through minijinja templates (templates/).

A repo’s pages are re-rendered only when its key changed: the blob ids of all its page sources, its code reference keys, its settings, and the global key (templates, the repo list in the navbar, the wiki binary). .jinja pages can show anything about the site, so they are rendered every time.
