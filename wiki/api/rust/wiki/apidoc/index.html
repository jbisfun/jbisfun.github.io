Module apidoc 

Source
Expand description

Code reference per repo, by each language’s own tool, into .build/api/<repo>/<tool>/: rust: cargo doc --no-deps (rustdoc) lua: LDoc js: JSDoc A tool that is missing or fails only warns: the site still builds. A reference is rebuilt only when the repo’s source id (see state) or its wiki.toml settings changed.
