Templating

Any .ejs file in a repo's docs/ (or in wiki/pages/) is a page, rendered like a PHP file: HTML with embedded code. This page is wiki/docs/templating.ejs.

Tags

<% code %>run JavaScript (loops, ifs)
<%= value %>print, HTML-escaped
<%- html %>print raw HTML
<%- include('partials/footer') %>include a template from wiki/templates or a relative path

Variables

  • site: title, repos, pages
  • repo: the current repo (name, pages, readmePage, docPages, apis ({tool, title, label, out}), description, web, head, ...)
  • page: title, out, front matter as page.data
  • url(path): site-relative path to a link from this page
  • md(source): render markdown

Front matter layout: false skips templates/layout.ejs; layout: other.ejs picks another one. Markdown pages can opt in to EJS with ejs: true.
