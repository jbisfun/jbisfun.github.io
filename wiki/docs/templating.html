Templating

Any .jinja file in a repo's docs/ (or in wiki/pages/) is a page, rendered with minijinja (Jinja2 syntax). This page is wiki/docs/templating.jinja. Layouts and partials live in wiki/templates.

Tags

{% for x in xs %}{% endfor %}statements (loops, ifs, set)
{{ value }}print, HTML-escaped
{{ html | safe }}print raw HTML
{% include "partials/footer.html" %}include a template from wiki/templates

Variables

  • site: title, repos, pages ({title, out})
  • repo: the current repo (name, index, readme_page, doc_pages, apis ({tool, title, label, out}), description, web, head, ...)
  • page: title, out, rel, front matter as page.data
  • url(path): site-relative path to a link from this page
  • md(source): render markdown

Front matter layout: false skips templates/layout.html; layout: other.html picks another one. Markdown pages can opt in to Jinja with jinja: true. Template pages are rendered on every build, since they can show anything about the site.
